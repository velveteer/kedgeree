Description

2D geometry primitives — a small module used to show off the Kedgeree Haddock theme.

It exercises the things a theme has to get right: section headings, data declarations with record fields, type classes with methods and instances, operators, and inline code / code blocks.

let unit = Circle origin 1
area unit  -- ≈ 3.14159
